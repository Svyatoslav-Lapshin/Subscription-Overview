# Subscription Overview

Subscription Overview is a full-stack web application for managing subscriptions and recurring costs.

Users can register, log in, add subscriptions and see an overview of their monthly spending.

## Features

- Register and login
- JWT authentication
- Refresh token with HttpOnly cookie
- Add, edit and delete subscriptions
- Active, Upcoming and Ended subscription status
- Categories and providers
- Monthly cost overview
- Cost by category
- Responsive desktop and mobile layout
- Demo user with sample data
- Scalar API documentation

## Tech stack
